# Hotel Booking

Hotel Booking — командный учебный проект по дисциплине «Управление проектами», группа 11. Цель проекта — подготовка прототипа сервиса бронирования гостиниц и комплекта проектной документации. Заказчик — команда № 3.

Управление проектом основано на гибридном подходе: базовый план определяет содержание, ресурсы и ограничения, а исполнение организовано в четыре двухнедельные итерации.

## Продукт

Прототип предусматривает поиск гостиниц и номеров, фильтрацию по датам, цене и вместимости, оформление и просмотр бронирований. Для администратора предусмотрены ведение каталога, просмотр бронирований и работа со статистикой.

В состав поставки входят серверная часть, веб-интерфейс, локальное окружение, демонстрационные данные, проверки и сопроводительная документация. Реальные платежи, SMS, мобильное приложение и промышленная эксплуатация находятся за границами проекта.

## Технологии

Программная основа включает Java 21, Spring Boot, Next.js и TypeScript. Для хранения данных и обработки событий используются PostgreSQL, MongoDB и Kafka. Конфигурация, зависимости и команды запуска приведены в репозитории реализации.

## Организация работы

Задачи ведутся в GitHub Projects со статусами «Сделать», «В процессе», «Сделано» и «Принято». Для задачи определяются ответственный, ожидаемый результат, критерий проверки и плановая оценка. Фактическое время учитывается по выполненной работе.

По итогам итераций команда демонстрирует результат заказчику, фиксирует решение о приёмке, актуализирует риски и план следующей итерации. Изменения документации и кода оформляются через pull request.
