## Продукт и границы

Гость регистрируется, входит, ищет подходящий номер по датам, цене и вместимости и получает подтверждение брони. Администратор управляет каталогом, проверяет бронирования и выгружает статистику. Уровень реализации — рабочий прототип, согласно [уставу](docs/phase-2/03-charter.md).

Поставки: исходники и веб-интерфейс; локальное окружение; синтетические демонстрационные данные; тесты и отчёт; инструкции; комплект управления и четыре протокола демо. Реальные платежи, SMS, мобильное приложение, промышленный хостинг и сопровождение после сдачи исключены.

## Получение и проверка документации

```sh
git clone https://github.com/MikHook12/Hotel-Booking.git
cd Hotel-Booking
python scripts/validate_docs.py
```

На Windows при необходимости используйте `py` вместо `python`. Проверка работает на Python 3.10+ без сторонних библиотек: контролирует локальные ссылки, уникальность идентификаторов, связи с ИСР и итоговые суммы исходного расчётного примера.

## Реализация и окружение

В отдельном репозитории обнаружены Java 21, Spring Boot 3.5.6, Maven Wrapper, PostgreSQL, Kafka, MongoDB, Flyway и Next.js/TypeScript. Это сведения из файлов проекта, а не результат запуска в данной работе. Проверенная ссылка на версию и ограничения зафиксированы в [паспорте реализации](docs/implementation.md).

Настройку выполняют по README реализации. В этом репозитории нет собственного приложения, поэтому команды запуска сервера здесь не приводятся. Готовность окружения фиксируется по [чек-листу](docs/phase-4/environment.md).
