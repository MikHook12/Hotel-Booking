# 🏨 Hotel Booking

**Hotel Booking** — проект системы бронирования гостиниц. Репозиторий используется для хранения материалов проекта и документации по этапам его разработки.

> **Текущее состояние:** в публичной структуре репозитория на момент подготовки README доступен каталог `docs/phase-2`. Исходный код готового приложения, конфигурация запуска и сведения о технологическом стеке в корне репозитория не представлены. Поэтому описанные ниже возможности не следует считать уже реализованными.

## 📌 О проекте

Цель проекта — разработать систему, упрощающую поиск и бронирование гостиничного размещения, а также работу с информацией о номерах и заказах.

В рамках дальнейшей разработки могут быть предусмотрены:

- просмотр гостиниц и доступных номеров;
- поиск вариантов размещения по параметрам;
- оформление и просмотр бронирований;
- управление данными о гостиницах и номерах;
- работа с пользователями и статусами бронирований.

**Важно:** это ориентиры для развития системы, а не перечень подтверждённых реализованных функций.
