# Порядок командной работы

Изменения кода и проектных документов выполняются в отдельных ветках. Pull request содержит описание результата, связанные задачи и сведения о проверках. Перед объединением назначается проверяющий из команды.

Проектные документы оформляются в официальном стиле от имени команды. Требования, решения и результаты формулируются без обращений к читателю и комментариев о процессе подготовки текста. Для планов указываются методика оценки и условия согласования. Для результатов приводятся проверяемые основания.

Файлы Markdown и CSV сохраняются в UTF-8. Названия участников и идентификаторы ИСР, историй и задач используются единообразно. Для Колесника указывается полное ФИО «Колесник Александр Владимирович» либо инициалы «Колесник А. В.».

Перед объединением выполняется `python scripts/validate_docs.py`. Фактические часы и решения о приёмке записываются в соответствующие журналы. Секреты окружения и персональные данные пользователей в репозиторий не включаются.
