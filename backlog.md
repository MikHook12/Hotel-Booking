# Бэклог продукта

Предварительный реестр: [backlog.csv](../phase-3/data/backlog.csv).18 историй охватывают гостя и администратора; указаны основной ИСР, MoSCoW, целевая итерация, предварительныеSP и проверки.

Порядок отбора: зависимости → Must → снижение риска → Should. Пакеты среды, управления и приёмки входят в общий трекер, но не получают искусственные пользовательские истории. Не считать пакет и его дочернюю историю двумя бюджетами.

После сверки с текущей реализацией для каждой истории фиксируются commit, ожидаемая проверка, фактический результат и остаточная работа. Доступный исходный код сам по себе не переводит историю в «Принято». Конкретные даты четырёх итераций согласуются отдельно.
