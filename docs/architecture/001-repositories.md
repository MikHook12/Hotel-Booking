# ADR001. Разделение репозиториев

Дата:16.11.2026. Статус: предложение для проверки команды.

Контекст: Hotel-Booking хранит документы курса, HotelReservationService — существующую реализацию. Смешение приводит к ложному выводу об отсутствии приложения и повторному планированию выполненной работы.

Решение: учебный репозиторий остаётся центром управления; исходники не копируются автоматически. Паспорт реализации содержит ссылку иcommit. Задачи управления связываются сPR/commit реализации. Критерии приёмки и учебные оценки принадлежат учебному репозиторию; команды запуска — README реализации.

Последствия: не возникает двух расходящихся копий кода; преподавателю нужны доступные ссылки на оба репозитория. Смена проверяемой версии фиксируется в протоколе и журнале изменений. При последующем объединении репозиториев сначала согласуются стратегия истории, сборка иCI; простое копирование каталогов не считается миграцией.
