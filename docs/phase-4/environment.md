Порядок выполнения

1. Получить репозиторий https://github.com/MikHook12/HotelReservationService и записать commit. 2. Проверить java -version, git --version, docker version, docker compose version; Maven — wrapper проекта либо mvn -version. 3. По README подготовить локальный .env; секреты не коммитить. 4. Запустить сборку и тесты фактической командой проекта. 5. Поднять зависимости фактическим compose-файлом, проверить health/logs. 6. Применить миграции и вымышленные фикстуры. 7. Пройти К 1/К 2 и негативную проверку ролей. 8. Перезапустить стенд и проверить сохранение. 9. Повторить на втором компьютере. Каждый шаг завершается логом и ссылкой на задачу ENV, а не отметкой по памяти.
