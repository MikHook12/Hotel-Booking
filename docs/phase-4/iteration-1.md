Покер и завершение

Покер: каждый из пяти участников независимо выбирает SP, минимальная и максимальная оценки объясняются, команда повторяет голосование до согласия. Результаты записываются в Protocol_Estimates.csv. Definition of Done: изменение сохранено в Git, проверено вторым участником, выполнены проверки истории, инструкция актуальна, результат доступен на стенде. «Принято» устанавливается только после решения заказчика. Демо: новая регистрация → вход → список отелей → номера; затем неверный пароль и пустой список. Сохранить версию, фактический результат и замечания.

Если функция уже соответствует требованию, новой разработки не требуется: сохраняются проверка и результат. Если обнаружено расхождение, оформляется конкретная доработка с уточнённой оценкой. Нельзя заново создавать готовую функцию ради исходного плана.
