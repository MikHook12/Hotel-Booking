## Проверка перед демонстрацией

1. Зафиксировать фактически используемыйcommit и сверить README именно этой версии.
2. Воспроизвести окружение поREADME реализации, сохранив версии и логи.
3. Проверить К 2 отдельно: README сообщает об ограничениях публичной регистрацииbrowserAPIv2. Выбрать разрешённый локальный сценарий и согласовать его с заказчиком; не выдавать недоступную регистрацию за готовую.
4. Пройти основной поток гостя иADMIN, негативные проверки и конкурентное бронирование.
5. Проверить событияCSV и сохранение данных после рестарта.
6. Сохранить протокол и оценить только оставшуюся работу. Факт трудозатрат команды переносить исключительно из реальных записей.

Команды тестов, указанные вREADME реализации: `./mvnw test` и `./mvnw -Pintegration verify`. Они выполняются в репозитории реализации; Windows используетmvnw.cmd. Интеграционные проверки требуют доступногоDocker. Для интерфейса использовать егоREADME; точныепорты, ключи и режимы не копировать в учебныйрепозиторий без необходимости.
