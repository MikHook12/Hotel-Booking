# Итерации 5–8

Четыре итерации по две недели. Для каждой создаётся каталог I1/I2/I3/I4 только при фактическом планировании. В нём сохраняются: план, версия демонстрации, решение заказчика, отчёт, изменения и следующий отбор.

| Общий файл | Назначение |
| --- | --- |
| [iteration-report.md](iteration-report.md) |Шаблон отчёта без вымышленных результатов |
| [acceptance.md](acceptance.md) |Чек-лист и протокол приёмки |
| [changes.csv](changes.csv) |Запросы и решения по изменениям |
| [time-log.csv](time-log.csv) |Фактические часы по конечным задачам |

Шаблон не считается прошедшим демо. Если факта нет, поле остаётся пустым или «не проведено». EVM рассчитывается после появления плановой версии и фактических данных.
