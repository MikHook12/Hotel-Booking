# Отчётность по итерациям

Для I1 используется [отчёт фазы 5](../phase-5/report.md), для I2 — [отчёт фазы 6](../phase-6/report.md). Расчёт показателей выполняется по [регламенту контроля](../control/README.md).

Состав отчёта: период, версия, принятые истории, фактические часы, PV, EV, AC, CV, SV, CPI, SPI, EAC, VAC, velocity, риски, изменения и следующее планирование. Итоговый отчёт I4 включает сравнение с поставками и критериями устава.
