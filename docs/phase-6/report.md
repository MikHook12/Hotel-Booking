# Отчёт по итерации I2

## Предмет отчёта

Отчёт отражает выполнение плана I2, результаты демонстрации, освоенный объём, фактическую стоимость и решения по следующей итерации. Отчётная дата, период и версия фиксируются при закрытии итерации.

| Показатель | План или основание | Факт |
| --- | --- | --- |
| Истории | US04, US05, US17 | Поле результата |
| Исходные SP | 9 | По согласованным оценкам принятых историй |
| План задач ч | 30 | По журналу времени |
| Фонд команды ч | 60 | По фактической доступности |
| Принятый результат | Протокол заказчика | По журналу приёмки |
| Velocity | Сумма согласованных SP принятых историй | Расчёт после приёмки |
| PV / EV / AC | Базовый план / приёмка / фактические часы | Расчёт по реестру контроля |
| CV / SV | EV - AC / EV - PV | Расчёт по реестру контроля |
| EAC / VAC | AC + (BAC - EV) / CPI; BAC - EAC | При CPI > 0 |
| Риски | Триггеры и меры | По результатам контроля |
| Изменения | Решения по CR | По журналу изменений |

## Порядок анализа

Причины отклонений рассматриваются по задачам, зависимостям и условиям окружения. Для каждого существенного отклонения указываются влияние на результат, ответственное лицо и корректирующее действие. Стоимость считается по условным ставкам проекта. Денежные расходы отражаются отдельно от расчётной стоимости труда.

Формулы и бюджетные единицы определены в [регламенте контроля](../control/README.md). Показатели рассчитываются после согласования базового плана и регистрации отчётных данных. Незаполненные значения не заменяются нулями.

## Решения по итогам

Регистрируются принятые истории, возвраты на доработку, изменения содержания, актуальные риски и состав следующего планирования. Для ретроспективы выбирается одно приоритетное улучшение с владельцем и критерием результата.
