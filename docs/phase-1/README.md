# Фаза 1. Концепция

Концепция извлечена из устава: небольшая гостиничная организация ведёт заявки вручную; нужен единый каталог и проверка доступности номеров. Гость ищет и бронирует номер, администратор изменяет каталог и просматривает брони.

Заказчик — команда№3; исполнитель — команда группы 11; уровень реализации — рабочий прототип. Это учебная легенда, а не утверждение о реальной организации.

Основание и точные границы: [устав](../phase-2/03-charter.md). Протокол интервью и подписи заказчика пока не представлены. Представитель заказчика подтверждает легенду и критерии до принятия baseline.
