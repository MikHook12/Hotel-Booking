# Проектная документация Hotel Booking

Комплект охватывает фазы 1–6 практического задания. Документы определяют содержание проекта, порядок исполнения, контроль результатов и взаимодействие с заказчиком.

| Раздел | Содержание |
| --- | --- |
| [Требования](requirements.md) | Матрица результатов практического задания |
| [Фаза 1](phase-1/README.md) | Концепция продукта |
| [Фаза 2](phase-2/README.md) | Методология, устав, стороны и ИСР |
| [Фаза 3](phase-3/README.md) | Оценки, сеть PERT, расписание и риски |
| [Фаза 4](phase-4/README.md) | Карта историй, бэклог, окружение и план I1 |
| [Фаза 5](phase-5/README.md) | План, демонстрация и контроль первой итерации |
| [Фаза 6](phase-6/README.md) | План, демонстрация и контроль второй итерации |
| [Контроль проекта](control/README.md) | Бюджетные единицы, EVM, velocity и журналы |
| [Состояние проекта](STATUS.md) | Состав результатов и контрольные действия |
| [Реализация](implementation.md) | Версия кода и технические ограничения |
| [Трекер](tracking/README.md) | Поля, статусы и учёт времени |

Редактируемые документы представлены в Markdown, расчётные данные и журналы — в CSV. Исходные документы второй фазы сохранены в DOCX. Для первой и второй итераций предусмотрены печатные отчёты PDF.
