# План итерации I1

Цель: проверка и доведение до демонстрации входа пользователя, каталога отелей и просмотра номеров. Продолжительность — две календарные недели. Даты начала и окончания фиксируются при согласовании плана итерации.

## Состав

Истории: US01, US02, US03. Исходная оценка — 8 SP. Методика: сопоставление с эталонной историей, независимое голосование участников и обсуждение расхождений. Согласованная оценка регистрируется в протоколе покера планирования.

План задач — 45 часов при фонде команды 60 часов. Фонд рассчитан из 6 часов в неделю на участника. Разница фонда и оценки задач используется при уточнении загрузки и не является автоматически расходуемым резервом бюджета.

Оценки задач детализируют пакеты ИСР. Суммы задач и родительских пакетов повторно не учитываются. Завершение задачи включает результат, проверку, ссылку и запись фактического времени.

## Условия завершения

Код и документы сохранены в репозиториях, проверки сценария пройдены, критические замечания устранены. Заказчик фиксирует решение по каждой истории. История с невыполненным условием возвращается в бэклог; её SP в velocity не включаются.
