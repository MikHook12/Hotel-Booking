# Фаза 3 Базовый план

Базовый план содержит оценки всех 25 пакетов ИСР, сетевой расчёт, ресурсное расписание, бюджет и реестр рисков.

| Документ | Содержание |
| --- | --- |
| [Оценки и PERT](estimates-pert.md) | Трёхточечные оценки, стоимость, зависимости и резервы |
| [Расписание](schedule.md) | Календарь, загрузка пяти участников и бюджет |
| [Сеть](network.svg) | Графическое представление зависимостей |
| [Диаграмма Ганта](gantt.svg) | Ресурсное расписание расчётного сценария |
| [Риски](risks.md) | Категории, приоритеты и меры реагирования |
| [Расчётные данные](data/README.md) | Исходные таблицы и модель |

Исходная модель: 220 часов работ стоимостью 167 800 рублей. Резерв составляет 30 часов и 22 800 рублей; общий плановый бюджет с резервом — 190 600 рублей. Условные ставки применяются для учебного учёта стоимости.

Параметры модели используются для анализа реализуемости. План оставшихся работ уточняется по состоянию компонентов и результатам приёмки. Изменение срока, загрузки и бюджета утверждается в порядке управления изменениями.
