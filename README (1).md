# Итерационное исполнение

Исполнение проекта организовано в четыре двухнедельные итерации. Фазе 5 соответствует I1, фазе 6 — I2, фазам 7 и 8 — I3 и I4.

Материалы первых двух итераций: [фаза 5](../phase-5/README.md), [фаза 6](../phase-6/README.md). Общие журналы времени, приёмки, изменений и рисков ведутся в [разделе контроля](../control/README.md).

По завершении каждой итерации фиксируются демонстрация, решение заказчика, освоенный объём, velocity и состав следующего планирования. Для I4 дополнительно выполняется сопоставление поставки с уставом и анализ уроков проекта.
