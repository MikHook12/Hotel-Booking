# Контроль качества проектных документов

Проверка выполняется перед публикацией редакции и перед демонстрацией. Ответственный — Колесник Александр Владимирович. Проверяющий — руководитель проекта.

| Объект | Критерий |
| --- | --- |
| Структура | Документы связаны с фазами задания |
| Терминология | Идентификаторы ИСР, историй и задач единообразны |
| Расчёты | Суммы, ставки, зависимости и бюджеты согласованы |
| Изложение | Официальный стиль от имени команды |
| Результаты | Указаны версия, проверка и основание решения |
| Реестры | Определён единый источник фактических данных |
| Навигация | Локальные ссылки открываются |
| Оформление | Таблицы и схемы читаемы; заголовки единообразны |

Проверка ссылок и расчётных ограничений выполняется скриптом scripts/validate_docs.py. Содержательная и визуальная проверка выполняется по итоговым файлам.
