# ADR001. Разделение репозиториев

Дата: 16.11.2026. Статус: проект решения.

## Контекст

Hotel-Booking содержит проектную документацию и материалы управления. HotelReservationService содержит серверную часть, веб-интерфейс, миграции, тесты и конфигурацию окружения.

## Решение

Проектные документы и программная реализация ведутся в отдельных репозиториях. Паспорт реализации фиксирует ссылку и идентификатор проверяемого коммита. Задачи связываются с изменениями кода через pull request или коммит. Критерии приёмки и расчётные оценки хранятся в Hotel-Booking; команды сборки и запуска — в HotelReservationService.

## Порядок сопровождения

Изменение проверяемой версии отражается в протоколе проверки. Навигация содержит ссылки на оба репозитория. Изменение структуры хранения оформляется отдельным решением с описанием переноса истории, сборки и непрерывной интеграции.
