# Регламент ведения трекера

Основной трекер проекта — [GitHub Projects](https://github.com/users/S4KHAR/projects/1), задачи размещены в [Issues](https://github.com/MikHook12/Hotel-Booking/issues). Состав: 25 пакетов ИСР, 18 пользовательских историй и 16 задач I1.

## Статусы

| Статус | Условие перехода |
| --- | --- |
| Сделать | Элемент включён в бэклог |
| В процессе | Исполнитель приступил к работе |
| Сделано | Результат подготовлен, проверен и связан с задачей |
| Принято | Заказчик зафиксировал положительное решение по применимым критериям |

## Поля карточки

Карточка содержит идентификатор, ответственного, связь с ИСР и историей, критерий результата и ссылку на материал. Поля проекта: Status, «Ответственный», «Итерация», «План сценария ч», «Факт ч». Числа в поле сценария относятся к исходной оценке пакета или задачи. Уточнённая оценка фиксируется в карточке с датой изменения.

## Представления

«Доска» показывает все элементы по статусам. «Бэклог» используется для табличного учёта. «Итерация 1» содержит US01–US03 и 16 задач I1. При планировании I2 используется фильтр «Итерация:I2» и [подготовленный бэклог](../phase-6/data/iteration-2.csv).

## Учёт времени

Первичный журнал фактического времени — [time-log.csv](../control/time-log.csv). Поле «Факт ч» в задаче содержит сумму её записей. Время записывается по конечной задаче с датой, исполнителем и ссылкой на результат. Родительский пакет и его дочерние задачи повторно не суммируются.

Истории оцениваются в SP, задачи — в часах, стоимость — по ставке исполнителя. Velocity учитывает принятые истории целиком. Возврат на доработку оформляется с причиной и ссылкой на решение заказчика.
