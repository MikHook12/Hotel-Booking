# Концепция проекта

Проект Hotel Booking направлен на создание учебного прототипа сервиса бронирования гостиниц. Заказчик — команда № 3. Продукт объединяет каталог, подбор номеров и оформление бронирования в одном пользовательском сценарии.

## Потребность

Пользователю необходим единый способ сравнения размещения по датам, цене и вместимости с получением подтверждения выбранного номера. Администратору необходимы инструменты ведения каталога и контроля бронирований.

## Роли и сценарии

Гость просматривает каталог, задаёт условия поиска, выбирает номер и оформляет бронь. Администратор поддерживает сведения об отелях и номерах, просматривает бронирования и выгружает статистику.

## Границы

Уровень поставки — рабочий учебный прототип с веб-интерфейсом и локальным окружением. Внешние денежные операции и рассылки исключены. Для демонстрации используются учебные данные.

Цели, поставки, ресурсные ограничения и критерии приёмки определены [уставом проекта](../phase-2/03-charter.md). Изменение концепции согласуется с представителем заказчика через журнал изменений.
